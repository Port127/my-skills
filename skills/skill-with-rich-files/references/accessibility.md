# Accessibility Checklist

- Every interactive element has a visible keyboard focus state.
- A status is conveyed with text or an icon shape as well as color.
- Form fields have persistent labels and errors are associated with their fields.
- Icon-only buttons have an accessible name and a useful hit area.
- Long file paths and code can be inspected without forcing the whole page to scroll horizontally.
- Reduced-motion preferences are respected for non-essential animation.

## Review prompt

For each state, ask: can a keyboard user reach it, can a screen reader name it, and can a user distinguish it without relying on color alone?
